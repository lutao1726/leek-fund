# 市场数据（第三批）

## 入口与功能

在命令面板运行 `LeekFund: 板块行情`、`LeekFund: 大盘云图`、`LeekFund: 个股异动`，也可从韭菜中心顶部进入。板块行情快捷键为 Windows/Linux `Ctrl+Alt+S`、macOS `Cmd+Alt+S`。

- **板块行情**：行业 / 概念板块搜索、涨跌幅和涨速排行、资金净流入 / 净流出前十、今日领涨个股。点击板块进入报价与成分股详情，可关注板块、查看个股资料并加入自选。
- **大盘云图**：行业、概念板块按市值分配面积，颜色表示涨跌幅；点击下钻成分股。另提供 A 股、科创板、创业板的个股市值分页，每页最多 100 只；点击个股查看资料。
- **个股异动**：22 类信号，支持全部 / 上涨 / 下跌和单一类型筛选、分页、查看公司资料及概念、加入自选。资料中的概念可跳转板块搜索。

关注板块存于用户配置 `leek-fund.followedBoards`，最多 100 个。加入自选会保留已有自选并去重；不自动创建持仓或交易。个股详情资料包括行情、公司简介、主营业务、行业与概念，源数据缺失时保留空缺或提示部分失败。

## 刷新、缓存与数据口径

板块概览每 60 秒刷新，板块报价、成分股和异动每 15 秒刷新，个股市值云图每 60 秒刷新；公司资料按打开 / 手动刷新加载。原生行情层共享缓存与同参数请求；手动刷新跳过有效缓存。页面隐藏、切换或关闭后取消自身请求与轮询；其他可见订阅者仍可使用共享请求。

所有页面展示采集时间，行情源提供时间时另展示行情时间。失败时若有历史快照，会保留原采集时间并明确标记缓存及错误；无数据时不会生成模拟行情。异动源通常只有时分秒，页面明确提示源未提供交易日期，不将本机日期当作交易日。

云图是当前可获取条目的相对面积展示：行业 / 概念成分可能重叠，面积之和不代表全市场总市值；个股云图只展示当前页，颜色分布不代表全市场涨跌比例。缺少有效市值的条目不分配虚构面积。板块成分按涨幅分页，独立个股范围按市值分页。涨速使用源字段，不宣称为固定三分钟区间；未提供三日累计涨幅。

数据来自东方财富公开行情接口，可能延迟、限流或调整。板块列表每类最多取 2,000 条，分页接口限制 1～200 页；截断、部分获取失败会提示。网络请求 12 秒超时，响应限制 2 MB，缓存最多保留 128 个键。

## 实现与验证

原生服务 `src/service/marketData.ts` 负责获取、校验、共享缓存及取消；`src/webview/leek-center/market-service.ts` 提供限定操作的消息桥。网页通过 `template-packages/leek-center/src/services/market.ts` 管理请求生命周期，不直接开放任意 URL 请求。

接口字段按各自协议解析：列表使用 `clist/get`；板块报价使用 `ulist.np/get`，避免误用 `stock/get` 的不同字段含义；个股报价使用 `stock/get`，公司资料使用 `RPT_F10_ORG_BASICINFO`。异动 `getAllStockChanges` 的类型列表保留字面逗号，避免源接口只识别第一个类型。

运行 `npm run test:market` 验证解析、分页、共享请求取消、缓存降级、偏好保存和桥接生命周期；`npm run test:ui -- --silent` 验证页面交互及轮询；`npm run check` 与 `npm run build` 检查类型及生产构建。构建和自动测试不替代在真实 VS Code 中的视觉与扩展安装验收。
