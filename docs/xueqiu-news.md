# 雪球关注用户

在 XueQiu News 栏目点击「+」，输入数字用户 ID 或用户主页链接，例如 `2657407918` 或 `https://xueqiu.com/u/2657407918`。保存关注列表不再依赖远程接口是否可用。

如果出现「获取失败，点击打开主页」，将鼠标移到用户行上查看错误。HTTP 410 等错误意味着当前请求被拒绝，不能据此判断用户不存在。点击该行可打开雪球主页；配置或更新 Cookie 后点击栏目刷新按钮重新获取昵称和动态。

Cookie 配置入口：栏目标题的钥匙按钮，或命令面板中的 `Leek: 配置雪球 Cookie`。在本人浏览器登录雪球，用开发者工具 Network 查看雪球请求的请求头，复制 Cookie 的值到插件输入框。Cookie 属于登录凭据，请勿发到聊天或日志中。当前入口沿用 `leek-fund.xueqiuCookie` 用户设置保存方式，输入时隐藏字符。

此次修复包括：等待匿名 Cookie 初始化、读取已有 Cookie 设置、设置请求超时、处理无 Cookie 响应、避免输出含凭据的完整请求错误，以及接口失败时保留关注用户并说明原因。登录状态、网络及雪球接口限制仍会影响访问；网页正常显示不代表插件的独立请求已获得登录授权。

验证：`node scripts/test-xueqiu-news.js`、`npm run test:core`、`npm run check`。匿名实测中，当前环境访问雪球首页和旧动态接口均返回 HTTP 410；尚未使用真实登录 Cookie 验证动态加载。
