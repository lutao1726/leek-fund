# AI 研究第一版

入口：韭菜中心顶部「AI 研究」、股票右键「AI 分析股票」、资产页「AI 持仓巡检」。命令面板也可搜索「AI 研究与分析历史」和「AI 持仓巡检」。沿用现有 AI 配置中的 Base URL、API Key、模型及历史区间。

## 个股报告

报告固定包含核心判断、支持依据、反对依据、后续观察条件、判断失效条件、数据缺口。原始行情快照、历史日线及最近100条快讯内的关键词关联结果随报告保存，可展开核对来源、行情日期与采集时间。

历史日线来自搜狐/腾讯；供应商复权口径没有独立核验。快讯失败时使用已有本机缓存并明确标注；未发现关联快讯不表示没有相关新闻。没有完整公告、财报和题材映射时不会宣称已覆盖这些资料。

## 持仓巡检

复用现有资产账本，只分析未清仓的股票。先冻结持仓数量和行情，逐股分析后汇总组合报告。不同币种独立计算持仓市值、最大单票占比、前三大占比及已知行业分布。任一持仓缺报价时，该币种的集中度显示数据不足。

占比只针对同币种股票持仓市值，不含现金，不代表全账户仓位；没有汇率、完整题材映射及相关性统计，不推断全账户集中度或联动风险已经充分覆盖。第一版每次最多50只持仓。

## 任务与本机历史

- 扩展端维护单任务执行队列，最多5个在途任务；重复启动同一股票或同一持仓巡检会复用在途任务。
- 页面关闭、菜单切换不取消任务；可手动取消，成功的逐股结果会保留。
- 扩展重启后，在途任务标记为中断，不自动重发付费模型请求。
- 重试创建新任务，使用最新持仓与行情，旧报告及证据保持原样。
- 最近30份任务保存在扩展全局存储目录 `research-v1.json`，使用临时文件写入后替换。API Key 不写入研究历史。
- 支持报告 Markdown 导出、单条历史删除和查看上一份同名个股报告。
- 模型 JSON 格式异常、截断或缺少必填栏目会显示失败，实际已返回的 Token 用量仍会记录。

## 用量

统计保留历史中的个股研究与持仓巡检调用，展示真实输入/输出 Token。模型没有返回 usage 时，以字符数粗估并单独展示，不并入真实用量。不包含旧版聊天及其他入口的调用，也不估算金额。删除历史会同步移出统计。

## 验证

运行 `npm run check`、`npm run test:research`、`npm run test:core`；前端运行 `npm test -- --watchAll=false --runInBand --runTestsByPath src/view/research.test.tsx src/view/portfolio.test.tsx`。`npm run build` 构建扩展及 Webview。

本次安装包为项目根目录下的 `leek-fund-3.23.5-ai-research-v1.vsix`。本机常规 vsce 打包的 npm 依赖树检测受到已有冗余包与版本标记影响；本次在构建完成后使用 vsce 的 pack API 按已安装的生产依赖及其传递依赖收集文件，未调整依赖版本，已核对研究服务、运行依赖和前端资源均包含在包内。

自动测试使用模拟模型和行情，不消耗真实模型额度。真实模型兼容性、线上数据源可用性及 VS Code 内交互仍需安装后检查。
