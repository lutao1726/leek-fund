# 第二版：今日摘要

入口为韭菜中心顶部「今日摘要」，或命令面板「LeekFund: 今日摘要」。

本次版本为3.23.6，安装对应 VSIX 后执行「Developer: Reload Window」重新加载窗口，使页面及配置声明同步生效。

页面汇总自选及未清仓持仓的报价、涨跌幅绝对值达到3%的标的、成交额、分币种持仓估值与集中度，并关联已有个股报告和最近可用持仓巡检。最近任务失败时仍能打开之前成功的报告；报告满7个自然日会显示提示。

快讯复用已有选股宝、金十轮询的最近100条共享缓存，匹配名称、完整代码或行业关键词，明确展示匹配原因。默认显示上海日期当天发布的关联快讯，可切换最近3个自然日或全部缓存。接收时间与发布时间分开，缓存为空不代表没有相关新闻。

摘要不自动调用模型、不启动额外行情或新闻轮询。刷新按钮调用已有行情刷新命令；页面隐藏或退出后停止摘要刷新，行情、持仓、新闻及研究记录变化时合并更新。

不同币种成交额分别排序；缺报价不补零，集中度在行情不完整时显示数据不足。历史行情显示交易日期和历史报价标记，盈亏显示为行情日估算口径。

验证：`npm run check`、`npm run test:summary`；前端运行 `npm test -- --watchAll=false --runInBand --runTestsByPath src/view/daily-summary.test.tsx`。

此阶段交付今日摘要。自动条件核验、报告差异比较和完整题材关联属于后续功能。
