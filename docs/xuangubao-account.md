# 选股宝账号配置

打开命令面板（Ctrl+Shift+P），执行 `Leek: 配置选股宝账号（安全存储）`，依次输入手机号和密码。国内手机号可省略 `+86`，其他地区请填写国际格式。密码输入会隐藏；取消输入不会覆盖原账号。

账号和密码保存在编辑器的 SecretStorage 中，不写入源码、settings.json、配置导出或 Webview。安全存储由编辑器负责加密，不跨机器同步；每台机器需分别配置。登录 Token 只保存在扩展进程内存中，最多缓存 24 小时。

执行 `Leek: 清除选股宝账号` 可删除凭据并清除登录缓存。更换账号后同样清除旧缓存。未配置账号时不发起登录请求，快讯接口以匿名方式访问，具体可用内容由选股宝决定。

旧源码和旧安装包曾包含固定凭据，修改配置方式不会撤销已泄露的密码；应修改原账号密码，旧安装包不要继续分发。

验证：`node scripts/test-xgb-auth.js` 和 `npx tsc --noEmit -p .`。测试使用模拟账号和请求，不登录真实账号。
