# LeekAgent：对话、Skills 与 IDE 模型

## 入口与使用

- 命令面板 `LeekFund: 打开 LeekAgent`，打开 LeekFund 侧栏中的 LeekAgent 视图。可用 VS Code 的「移动视图」将其移至辅助侧栏。
- 编辑器标题栏星标、股票树灯泡「LeekAgent 解读标的」预填股票代码。
- 韭菜中心顶部「LeekAgent」提供较宽的同功能页面。
- 支持原生 Chat 的 VS Code 中可使用 `@leek`，支持 `/summary`、`/portfolio`、`/explain`、`/scan`、`/brief`；它尊重 Chat 当前选中的 IDE 模型。不同编辑器不一定提供原生 Chat，仍可使用侧栏。

先点击「刷新模型」，选择 IDE 模型或「自带 API」。IDE 模型由已安装的模型提供扩展通过稳定 Language Model API 暴露，可能要求登录、授权或额度；无法直接使用其他编辑器未向该 API 暴露的私有模型。自带 API 沿用 `leek-fund.aiConfig` 的 Base URL、API Key 和 model。地址支持 HTTPS 或本机 HTTP，不自动切换模型、不自动重试。首次 IDE 授权由编辑器处理。

输入问题后 Enter 发送，Shift+Enter 换行。回复流式展示为安全纯文本，Markdown 原文可导出；支持停止、继续追问、新建、切换、删除会话。停止后保留已接收内容；新的问题不会混入旧请求的迟到回复。切换页面或隐藏侧栏不会终止任务，需手动停止；退出扩展后任务中断且不自动续发。

会话、生成状态、模型名称与工具证据保存在扩展全局存储目录 `agent-v1.json`，最多10个会话、每个10轮；历史总大小超过7MB时回收最旧的非运行会话。模型上下文最多使用最近6轮完整回答与部分原始证据，旧快照明确标为历史。删除会话会停止对应生成。旧「AI 研究」的任务与历史保持独立，仍使用原模型配置。

## 内置 Skills

| 命令 | 自动采集与流程 |
| --- | --- |
| `/summary` 或 `/s` | 近期快讯，按主题整理来源与日期 |
| `/brief` | 近期快讯，输出三条有证据的要点 |
| `/portfolio` 或 `/p` | 本机持仓、自选及缓存报价，按币种整理缺口和集中度 |
| `/explain sh600519` 或 `/e sh600519` | 股票报价、近三个月日线、近期快讯；未给有效代码时要求补充 |
| `/scan` | 行业 / 概念涨跌和净流入前十、自选及快讯，整理观察清单 |

普通对话也可按需调用只读工具：`watchlist`、`portfolio`、`quote`、`history`、`news`、`sectors`、`board`、`changes`。每次数据采集保存带唯一编号的证据，可在回复下展开原始资料和采集时间。新闻等外部文本作为资料输入，不作为运行指令。工具不能执行命令、读取任意文件、修改配置、增删自选或交易。

## Skill 安装与启用

点击 LeekAgent 模型栏的「Skills 管理」，可搜索全部内置和已安装定义，查看正文、来源和允许的只读工具，并使用开关启用 / 停用。快捷按钮、手动 slash 和原生 Chat 均使用当前已启用的有效定义；状态保存在扩展全局设置中，重启保留。正在运行的回答沿用启动时的定义。

- **导入目录**：选择单个技能或技能集合目录，递归查找 SKILL.md，最多8层、5,000个条目、50个技能；跳过 .git、node_modules、.venv 和符号链接。
- **导入 ZIP**：支持普通 Store / Deflate ZIP，不支持加密、多卷或 ZIP64；最大20MB、5,000个条目，声明的展开大小最多100MB。只读取最多50个 SKILL.md，不解压其他文件；拒绝路径穿越、符号链接、重复路径或校验不一致的包。
- **从 GitHub 安装**：填写 `https://github.com/所有者/仓库`，下载默认分支的公共仓库 ZIP，限制与本地 ZIP 相同。私有仓库、分支 / 文件 / 子目录 URL 暂不支持；过大仓库可仅下载所需技能后导入目录。下载可取消，网络错误可改用本地导入。

新安装默认停用。导入完成后查看正文并打开对应开关，再点「使用」预填 slash。安装位置为 `~/.leekfund/skills/<slash>/SKILL.md`，只复制文档，不安装脚本、附件、依赖、MCP 或第三方工具。相同用户目录或同 slash 不覆盖，需先卸载旧版本；多技能包会分别报告成功和跳过原因。批量导入中的有效技能可安装，其他项会明确提示。

内置、用户、工作区的同名定义都保留在管理列表；低优先级项标记「已被覆盖」，不能直接启用或使用。停用高优先级定义不会自动回退。卸载用户定义后可能恢复同名内置定义。内置和工作区定义可停用；卸载按钮仅用于用户目录，确认后只移除 SKILL.md，目录内其他文件保留。

## 自定义 Skills

用户目录：`~/.leekfund/skills/<名称>/SKILL.md`；已信任工作区：`<工作区>/.leekfund/skills/<名称>/SKILL.md`。同 slash 的优先级为工作区 > 用户 > 内置；多根工作区按列表顺序加载，后加载的同名定义覆盖前者。未信任工作区不加载项目 Skill。编辑完成后在管理页点击「刷新列表」。Skill 不会执行脚本，也不需要安装依赖。

```markdown
---
name: 板块观察清单
description: 核对板块热度、自选和待跟踪事项
slash: sector-notes
tools:
  - sectors
  - watchlist
  - news
---
先按行业和概念分别列出数据来源及时间。
输出事实、与自选的关联、反对依据及待核实事项。
每条关键结论引用证据编号，不推定成分重叠的板块可以累加。
```

LeekAgent 原生格式支持上述四个元数据字段和正文，显式 tools 会自动预取所列资料。`slash` 为小写字母开头、最长31位的字母 / 数字 / 连字符；`s`、`p`、`e` 保留为内置别名。`tools` 使用逐行列表，最多8种内置工具。

也支持普通 `name`、`description` 元数据的 SKILL.md：name 作为 slash（最长31位英文短名称），description 可使用单行引号或 `>-` / `|` 文本块。正文作为分析流程使用，模型按需调用 LeekAgent 只读工具，不预取全部资料。额外 metadata、allowed-tools 等声明不会授予执行能力，正文引用的脚本和附件不会导入。复杂 YAML、多行引号不支持，可改为上述原生格式或块文本。

每个作用域最多加载按目录名排序的前50项，单文件不超过32KB且含元数据总长不超过24,000字符；符号链接不作为普通 Skill 文件加载。无效文件会显示提示。暂不支持关键词自动触发或第三方可执行工具。

## 数据与限制

发送问题及工具取得的持仓、行情和资讯会提交给当前所选模型。凭据不进入新会话历史或新模型列表；现有 API 配置的存储方式不在本次变更范围。

报价和市场数据复用已有服务。自选和港美股报价主要使用本机缓存；A股资料来自东方财富；历史日线与快讯复用现有研究数据源。快讯仅近期样本，不能当作完整新闻或公告覆盖。缺失、过期、部分失败或长度截断会保留标记，不生成替代行情。云图、板块的分页与成分重叠限制同市场数据页。工具时间字段保留来源口径，不能将采集时间当作交易日期。

每个回答最多5次模型往返、12次只读工具调用、3分钟；最多两个会话同时生成。问题最多8,000字符，回答最多24,000字符，工具资料预算约24,000字符，过长资料以标记的片段提供。达到限制时保留内容并提示失败。模型需支持流式输出及工具调用，不兼容或超出容量时显示失败；没有消耗真实额度的自动兼容测试。

## 开发验证

`npm run test:agent` 覆盖真实会话循环、Skills、工具结果回传、取消与迟到隔离、持久化中断、IDE 取消令牌和 API 流式工具参数拼接。`npm run test:agent-skills` 验证导入格式、ZIP 校验、安装去重、停用持久化及卸载边界，文件测试只使用临时目录。`npm run test:ui -- --silent` 验证交互及其他页面回归；`npm run check` 和 `npm run build` 检查类型及生产资源。测试使用模拟模型，不请求付费服务。真实 IDE 授权和不同兼容 API 的服务端行为仍需在对应环境验证。
