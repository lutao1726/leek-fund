# 股票增强功能（第一批）

运行要求：VS Code 1.100.0 或以上。现有市场分类、自选代码与股票成本配置继续保留，基金功能沿用当前工作区的移除状态。

## 分组与排序

- 在 Stock 标题栏点击「新增股票分组」，或运行 `LeekFund: 新增股票分组`。首次新增会启用自定义分组。
- 「切换市场分类 / 自定义分组」可随时切回原来的市场视图；切换不会清空分组。
- 右键分组可重命名、删除；删除后成员移至默认分组，自选与持仓均保留。默认分组不能删除。
- 分组行的「+」可直接添加成员；股票右键「移动到分组…」可跨组移动。
- 拖动分组到另一分组前面可调整分组顺序；拖动股票到分组会追加到末尾，拖到股票上会插入到它前面。支持多选股票移动。
- 标题栏「选择股票排序方式」支持手动顺序、涨跌幅与成交额升降序。拖动或置顶股票会恢复手动顺序。行情未提供成交额时排在末尾；金额按行情源的原币种口径排序。
- 「我的持仓」是自动生成的分组，显示未清仓股票，不作为拖拽的目标分组。
- 韭菜中心自选页同步显示分组与顺序，并支持按名称或代码搜索；按 `/` 可聚焦搜索框。

分组保存在用户设置 `leek-fund.stockGroups`，采用独立 ID。原 `leek-fund.stocks` 仍是自选代码来源，新代码自动归入默认分组；迁移不会覆盖原代码列表。

## 自选快速定位

Windows/Linux：`Ctrl+Alt+W`；macOS：`Cmd+Alt+W`。也可点击 Stock 标题栏搜索按钮，或运行 `LeekFund: 自选快速定位`。

输入名称或代码后，可定位侧栏、打开走势、在韭菜中心打开、触发 AI 分析或置顶。检索本身使用本地自选与缓存；打开走势和 AI 分析仍需要各自的数据源或模型配置。

## 资产管理

点击韭菜中心顶栏「资产」、Stock 标题栏资产按钮，或运行 `LeekFund: 资产管理中心`。

- 新增或编辑股票数量、平均成本；支持从现有自选填入名称和代码。
- 加仓按数量加权重算平均成本；清仓保留记录但不计入持仓市值和浮动盈亏。清仓记录可重新建仓。
- 删除持仓不会删除自选；删除自选也不会删除持仓。未在自选中的持仓仍会请求行情。
- 人民币、港币、美元分别汇总，不直接混加。显示报价时间，缺少行情时标为未知并提示汇总不完整。
- 今日盈亏按当前持仓数量与报价估算，当日交易、交易费用与汇率变化可能造成与券商账单的差异；这里是成本账本，不是逐笔成交账本。
- 状态栏与资产页共用计算结果，点击收益状态栏可直接打开资产页。

持仓继续存储在 `leek-fund.stockPrice`，兼容原成本价设置；JSON 导入导出通过原生文件对话框选择路径。导入采用合并方式，同代码覆盖，其余记录保留；确认前会校验整个文件。支持最多 5 MB / 10,000 条记录。

账本格式：

```json
{
  "version": 1,
  "positions": [
    { "code": "sh600519", "name": "贵州茅台", "amount": 100, "unitPrice": 1500, "isSellOut": false }
  ]
}
```

## 开发验证

```powershell
npm run check
npm run test:core
npm run test:ui
npm run build
```

`build` 会编译扩展并构建 Webview。核心测试不依赖网络或实际行情，覆盖配置迁移、排序、跨组移动、持仓估值与持久化；资产页交互测试覆盖数据加载、保存失败恢复和清仓消息。实际编辑器内拖拽、真实行情与 AI 调用仍需在 Extension Development Host 中联调。
